# Explicit Studio publication — 13 October 2026

This release supersedes automatic sharing of all owner Journal trades and observations. The owner explicitly requires records to remain private until they press Publish to members in Studio, and requests observation images in the feed.

Both private live-feed functions now require a matching circle_posts source linkage with status published and published_at <= now(), including the observation detail endpoint. Existing manually published records remain visible (verified 4 trades and 1 observation); drafts, unselected records, future publications and unpublished records are excluded. No source rows, existing publication states, images or stored trade details were changed. Applied reference: database/migrations/20261013075046_studio_manual_publication_gate.sql. Do not reapply earlier automatic-feed functions over this gate.

Admin-only circle_studio_sources is an invoker RPC requiring registered administrator MFA and auth.uid() source ownership/RLS. It pages through small source lists and returns one original record on selection, preserving the loading improvements. Applied reference: database/migrations/20261013075141_studio_review_sources.sql. The interface shows paired original trade charts, complete saved details, original observation notes/images, a required review checkbox, Publish to members, publication status, and a link to manage/unpublish existing publications. It uses the existing guarded publish RPCs rather than new publication writes. Publishing an approved record permits subsequent Journal edits to synchronize until it is unpublished.

Observation image previews now load lazily only for visible, published records. Original notes/charts are still available on opening; no full-archive preload or new persistent private-data cache. Composer default saves privately; only its explicit publish choice shares a newly created observation. No real records were published as a test.

Validation: PostgreSQL tests cover published/draft/future/anonymous/paid/MFA boundaries, blocked detail lookup for unpublished sources, publishing and withdrawal visibility, admin-only owner-isolated review lists/details, paired trade slots, and original source preservation. Client pagination/detail/error tests, existing Studio/access/workspace/observation/execution tests, legacy publication tests, full root build, design checks and live Studio/member checks. Production receipt is reported in chat and the pull request.
